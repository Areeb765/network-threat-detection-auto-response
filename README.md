# Network Threat Detection & Auto-Response Tool

> **Status: In Progress**

I started this project to get more hands-on experience with cybersecurity, Linux networking, and Python. The goal is to build a tool that can monitor network traffic, identify suspicious activity, and respond to certain threats automatically.

The project will focus on detecting behavior such as port scans and repeated connection attempts. When suspicious activity is detected, the tool will log the event and can use Linux `iptables` rules to block the source IP.

## What I'm Building

* Monitor network traffic using Python and Scapy
* Track activity from different source IP addresses
* Detect possible port scans and repeated connection attempts
* Log suspicious network activity
* Use `iptables` to block IP addresses when certain detection rules are triggered

## Tools & Technologies

* Python
* Linux
* Scapy
* iptables
* TCP/IP
